# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/stelewis/jbt/security/advisories/new). Do not open a public issue for a vulnerability.

Never include financial records, credentials, access tokens, account details, or other personal data in a report. Use the smallest synthetic example that demonstrates the issue.

The project is pre-alpha. Only the latest published release is eligible for a security fix.
